# 校准协议冻结与 F2-F4 实现门禁（历史索引）

> 本文件仅用于保留旧路径，不再冻结当前协议、参数或门禁。

当前 V3 校准协议和实施语义统一以：

```text
docs/V3六型号真实校准最终设计.md
```

为准。

当前冻结边界：

- CAL_MQTT_V3 会话负责 CAP / BEGIN / SET_POINT / RAW / STAGE / APPLY / SET_OUTPUT / COMMIT / READ / ABORT / RELEASE；
- 244B CALP payload 保持当前版本兼容；
- Output 区是 11点 `TargetCurrent -> CorrectPWM`；
- OCO wire 区保持11个兼容pair，但必须由 `0% Offset + 90% Gain` 同一直线生成，禁止解释为11点独立采样PWL；
- BEGIN 绑定 Product Profile、所选校准电压和 CalibrationSpan；
- BUILD 不使用精度百分比/稳定百分比作为收点门禁；
- APPLY 后 QUICK/FULL 只测量并记录误差，非零误差不提前阻断；
- COMMIT/READ 只使用安全、结构、CRC、Flash和回读一致性硬门禁。

任何历史 V2、旧表长度、旧功率专项参数、旧容差规则和旧上下文定义都只允许从 Git 历史追溯，不得重新复制到当前 V3 文档或代码。
