# 历史实现快照：旧 F2-F4 校准门禁

> **状态：LEGACY / DEPRECATED / 不得作为当前 Codex 实施规范**

本文件原来用于记录早期量产校准框架、11点 codec、旧安全门禁和旧 Flash 候选方案。随着 50W 参数职责、Protocol V3、Flash A/B 和上位机职责重新冻结，原文件中的规范性结论已经失效。

## 1. 仍可保留的历史事实

以下内容可以继续作为工程背景：

- 设备校准点仍为 11 点，Level `0/20/.../200`；
- 外部 DC5200 / 电子负载协议仍由上位机负责；
- `SV=cal` 与普通 `prop/ctrl/plan/OTA` 路由隔离；
- 旧实现已经存在 sessionId/seq、BEGIN/HEARTBEAT、SET_POINT、RAW、STAGE、APPLY、COMMIT、ABORT、RELEASE 等基础框架；
- 旧实现已经有 Raw Snapshot、CRC、Generation、Commit Word 等可复用基础；
- HIL、Keil/MAP、真实 Broker 不能被主机测试替代。

## 2. 原文件中已废弃的内容

不得继续按以下旧结论实现：

- 50W默认 SET_OUTCUR=890mA；
- HWMAX=1680mA 与 Hardware Max 不区分；
- 固定校准电压绑定 Calibration；
- CAL_MQTT_V2 作为冻结协议；
- 旧 Profile Context 作为运行授权；
- 缺少 Calibration 时普通输出失败关闭；
- 旧共享页 Calibration A/B 作为最终 Flash 地址；
- 旧校准安全必须依赖 boot-inhibit 才允许正常设备输出。

## 3. 当前目标

50W当前冻结：

```text
Hardware Max       = 1680mA
Default HWMAX      = 1400mA
Default SET_OUTCUR = 893mA
RS3                = 120mΩ
```

目标协议：

```text
Calibration MQTT Protocol V3
```

目标 Flash：

```text
Config A/B
Calibration A/B
Runtime A/B
每个Owner独占2KiB物理擦除页
```

新 Calibration Flash 结构在逐Byte冻结前只称 `Target Calibration Record`，不得继续沿用旧文件里的 Record v1/v2/v3 口径作为目标版本。
