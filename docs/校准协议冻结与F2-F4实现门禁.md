## 已冻结的驱动器 codec

- 驱动器为 9600 8N1；帧为 `3A CMD OFFSET LEN DATA SUM 0D 0A`，SUM 是 `CMD+OFFSET+LEN+DATA` 的低 8 位，字段大端。
- SET/ACK 为 `0x24/0x25`，QUERY/REPLY 为 `0x26/0x27`；ACK 数据 `0x55` 来自原件逐步示例，不是代码猜测。
- 校准表固定 11 点 `0,20,...,200`，每点 18 字节，表载荷 198 字节，黄金帧 205 字节；Host 测试逐字节回环原件黄金帧，checksum 为 `0xCC`。
- 最大值上下文 offset `0x07` 为大端 `UAC float32 + Umax u16(0.1V) + Imax u16(0.001A)`；单点读取 offset `0x08` 回复 6 字节。
- 电子负载 SCPI 与 DC5200 原始帧保持为独立协议；本提交没有把它们混入驱动器 codec，也没有新增 USART2 读取者。
- `sys_calibration_dc5200.c` 只解析 DC5200 综合页：请求/回复头尾、60 字节页长度、CCITT(init=0) CRC 和大端整数均有原件黄金向量；电子负载的 ASCII+LF 命令没有被当作“无回复即成功”，仍待独立 transport/查询闭环。
- 电子负载命令边界固定为独立 SCPI 文本（例如 `MODE CURR\\n`、`CURR <A>\\n`、`INP ON/OFF\\n`、`MEAS:VOLT?\\n`、`MEAS:CURR?\\n`、`MEAS:POW?\\n`）；发送接受不等于业务成功，必须有查询回读或测量闭环。

## F2–F4 状态

- `SV=cal` 已与普通 `prop/ctrl/plan/OTA` 路由隔离，支持 capabilities、BEGIN/HEARTBEAT 租约、SET_POINT、RAW 校验入口、STAGE_CONFIG、READBACK、临时 APPLY、COMMIT、ABORT、RELEASE。
- MQTT 业务结果先进入 `sessionId+seq` 单项结果缓存；发布失败时重复 seq 返回相同结果与精确暂存回读。JSON 二进制载荷以十六进制字符串传输，避免 198 个 cJSON 数字节点耗尽发送池；旧数组形式仍只作为严格输入兼容。
- SET_POINT、APPLY 和 RAW 底层驱动事务在 `SYS_CALIBRATION_NONZERO_OUTPUT_ENABLED=0` 时失败关闭。RAW 已完成严格帧/方向校验，但底层 transport 仍显式 `NOT_AVAILABLE`，不抢占 BL0942 使用的 USART2。
- 50W 固定上下文为 MID=1、RS3=120mΩ、额定设点 890mA；I-V 表和 `I<=1.4A/P<=50W` 纯函数限幅已测试。100W MID=3/RS3=50mΩ只保留为禁用上下文，75W不冒充100W。
- A/B 记录具备 magic、版本、generation、CRC32、commit-word，commit-word位于记录末尾以支持最后写入；boot-inhibit记录具备独立A/B选择和撕裂校验。两者都是不绑定地址的框架。

## 明确未关闭的门禁

- `SYS_CALIBRATION_FLASH_COMMIT_ENABLED=0`：共享 2KiB 擦除页所有权、候选地址边界和新鲜 Keil MAP 未完成，不能提交或宣称固定地址。
- 生产安全 ready 没有伪造：记录读取/持久化后仍需集成验证；默认状态保持 boot-inhibit，非零校准输出关闭。
- OCP/OPP 的硬件阈值、延迟、滞回，direct-PWM 硬件安全上限，Keil 构建/MAP、MQTT真实Broker联调和实机 HIL 均不能由 Host/ARM/XML 测试代替。
- 当前运行时在 50W 路径加入软件 50W/1.4A 封顶、1.68A 立即 fail-off；这不是硬件保护或 HIL 证明。
