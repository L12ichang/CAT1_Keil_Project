# 中科协议快速接入测试验证报告

## 1. 接入点结论

本次按最小改动接入，不重构原有业务框架。

- MQTT/4G AT 时序入口：`Core/Src/LampProtocolLib/NbDriver.c`
- 登录与心跳调度入口：`Core/Src/LampProtocolLib/TcpClient.c`
- 平台下行 JSON 解析入口：`Core/Src/LampProtocolLib/Json_Protocol.c`
- 灯具执行链路：`dim_level -> dim_ready() -> Core/Src/gateway/net_dim.c -> sys_pwm_output()`
- Keil App 烧录入口：`MDK-ARM-8008000/project.uvprojx`

## 2. 已实现功能

### 2.1 中科 MQTT 协议模块

新增：

- `Core/Src/LampProtocolLib/mqtt_zk_protocol.h`
- `Core/Src/LampProtocolLib/mqtt_zk_protocol.c`

实现内容：

- 服务器：`47.120.15.220:1883`
- MQTT 版本：4
- ClientID/Username：15 位 IMEI
- Password：IMEI 三段 CRC16-MODBUS 取反后按 3-1-2 顺序拼接
- 主题：
  - 平台到设备：`MS/{IMEI}/plt2dev`
  - 设备到平台：`MS/{IMEI}/dev2plt`
  - 升级下行：`MS/{IMEI}/pcp2dev`
  - 升级上行：`MS/{IMEI}/dev2pcp`
  - 遗嘱主题：`MS/{IMEI}/offline`

### 2.2 登录认证

`NbDriver.c` 中的 MQTT AT 时序已切换为中科平台：

1. `AT+QMTCFG="recv/mode",0,0,0`
2. `AT+QMTCFG="version",0,4`
3. `AT+QMTCFG="keepalive",0,120`
4. `AT+QMTCFG="qmtping",0,30`
5. `AT+CGSN`
6. `AT+QCCID`
7. `AT+QMTOPEN=0,"47.120.15.220",1883`
8. `AT+QMTCONN=0,"{IMEI}","{IMEI}","{PASSWORD}"`
9. `AT+QMTSUB=0,1,"MS/{IMEI}/plt2dev",1`
10. `AT+QMTSUB=0,2,"MS/{IMEI}/pcp2dev",1`

MQTT 连接成功后，`TcpClient.c` 调用 `zk_publish_login_packet()` 发布 `CT=L` 登录包。平台返回 `CT=L` 且 SN 匹配后，进入在线状态。

### 2.3 心跳保活

`TcpClient.c` 主循环每秒调用 `zk_mqtt_session_process()`。

- 登录 ACK 等待超时：重新发送登录包
- 在线状态：每 60 秒发布 `CT=H` 心跳包
- 收到平台 `CT=H` 响应：刷新心跳时间
- 收到 `+QIURC: "pdpdeact"` 或 `+QMTSTAT` 断链状态：复位登录会话

### 2.4 开关灯控制

`Json_Protocol.c` 识别中科平台 `CT=W` 下行，控制字段位于 `DT`。

已兼容字段：

- `sw`
- `switch`
- `onoff`
- `power`
- `on`
- `light`
- `state: "on" / "off"`

执行策略：

- 关灯：`dim_level = 0; dim_ready();`
- 开灯：恢复上次非零亮度，若无记录则使用 100%

### 2.5 亮度调节

已兼容字段：

- `bri`
- `Bri`
- `brightness`
- `level`
- `bl`
- `dim`
- `Dim[0]` 内同名亮度字段

亮度范围限制为 `0..100`，执行链路复用原有网络调光逻辑。
