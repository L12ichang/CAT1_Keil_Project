8008000 工程：电源启动时 PWM 异常排查图

这页把当前代码启动阶段会影响 PWM 的地方画出来。重点看三个动作：TIM1 一启动就输出、随后写 0、主循环马上软启动到 100%。

一句话结论

最可疑

TIM1 PWM 启动瞬间

初始化时 Pulse = 500，然后马上 HAL_TIM_PWM_Start()。在写入最终关断值前，可能出现短暂 50% PWM。

容易混乱

0% 的比较值不一致

初始化用 CCR=1000 表示 0%，但 set_PWM_OUT(0) 可能写成 CCR=0。PWM2 模式下这两个值不是一回事。

必然发生

开机软启动到 100%

主循环第一次执行 sys_pwm_fade_output(0, 100)，设备会主动从 0 渐变到 100%，不是等待平台亮度。

关键波形理解

当前最需要用示波器确认：在 TIM_OCMODE_PWM2 下，你这块硬件到底是 CCR=0 关断，还是 CCR=1000 关断。代码里两个地方对“0%”的写法不一致。

代码动作 写入值 风险
TIM1 配置通道 Pulse = 500 启动 PWM 时可能先输出 50%。
初始化结尾 CCR = 1000 代码注释认为这是 0% 输出。
set_PWM_OUT(0) CCR = 0 + PWM_OFFSET 如果 PWM_OFFSET=0，这和初始化的 0% 不一致。

建议改法

第一步

先统一真正的关断比较值

用示波器确认 PA8 上 CCR=0 和 CCR=1000 哪个是真正关断。确认后，初始化和 set_PWM_OUT(0) 必须都使用同一个值。

第二步

PWM_Start 前就设置关断

不要用 Pulse=500 作为初始值。把 sConfigOC.Pulse 改成关断值，再启动 PWM。

第三步

先关 OCO，再开 PWM

把 oco_init() 提前到 hw_tim1_pwm2_init() 之前，让输出使能脚先进入确定的关闭状态。

第四步

确认是否需要开机 100%

如果设备上电不应该自动亮灯，把 softstar 默认关闭，或改成加载到上次亮度/平台亮度后再输出。

现场验证顺序

测量点 看什么 判断
PA8 / TIM1_CH1 上电后是否出现短暂 50% 或满占空波形 有的话，优先改 TIM1 初始化初值。
PC13 / OCO PWM 启动前是否已经稳定关闭 不稳定的话，提前 oco_init()。
启动后 1-3 秒 PWM 是否从 0 逐步升到目标值 这是 softstar 软启动逻辑，不是平台下发。
工厂参数 SET_OUTCUR、HWMAX_OUTCUR、OP_PWM_OFFSET 参数错误会导致最终 PWM 比例错误。
