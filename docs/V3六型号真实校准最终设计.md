# V3 六型号真实校准最终设计

> 适用：50W / 75W / 100W / 150W / 200W / 240W 一体化电源。本文是 V3 校准唯一实施口径；旧的 50W 专项、36V-only、HWMAX=36V I-V 上限等方案不再作为实现依据。

## 1. 不可破坏的默认调光基线

未校准、无有效曲线、或目标电流超出已校准覆盖范围时，必须严格走历史默认链路：

```c
PWM = percent * SET_OUTCUR * PWM_USEFUL_RANGE /
      (HWMAX_OUTCUR * 100U);
```

- `SET_OUTCUR`：Factory 可配置额定输出电流。
- `HWMAX_OUTCUR`：Factory 可配置 PWM 满量程/硬件最大电流分母。
- **禁止**用 36V I-V 最大允许输出电流替换 `HWMAX_OUTCUR`。
- Product Profile 中的 HWMAX 只提供首次初始化/无效恢复默认值，正常启动不覆盖 Flash 中已保存的 Factory 值。
- 校准不得修改 SET/HWMAX。

六型号默认 HWMAX：1680 / 2150 / 2800 / 4500 / 6000 / 7000mA。

## 2. 11 点与 244B 保持不变

固定点：Level=0,20,40,...,200，共 11 点。V3 operation、payload version、244B 长度保持不变。

协议仅做向后兼容扩展：
- `BEGIN` 可带 `calibrationVoltage01V`、`calibrationSpanMa`。
- `SET_POINT` 可带 calibration-only `logicalPwm`，用于极少数端点覆盖探测。
- 新校准流程要求固件回报实际 `actualPwm`；通用解析保持兼容旧 V3 回复。

## 3. 校准电压与量程

正式校准电压必须是 Product I-V 表的精确节点：25/29/32/36/40/44/48/52/56V。

```text
CalibrationSpan = min(
    runtime HWMAX_OUTCUR,
    IVLimit(selected Vout),
    product absolute Hardware Max,
    explicit current/power safety envelope
)
```

SET 不参与 CalibrationSpan 计算。

## 4. 输出电流控制校准：BUILD → inverse PWL

### 4.1 第一轮 BUILD

11 个固定 Level 由 CalibrationSpan 形成准确目标轴：

```text
TargetCurrent[i] = CalibrationSpan * Level[i] / 200
```

第一轮必须**绕过任何已保存校准曲线**，使用历史未校准 HWMAX 基线输出。每点稳定后同时保存：

```text
TargetCurrent[i]
ActualPwm[i]
ExternalActualIout[i]
OCO Raw
BL0942 Raw
External V/I/P truth
```

这一步是测量真实 plant response：

```text
ActualPwm -> ExternalActualIout
```

不是把测到多少电流直接当成最终 Output 校准轴。

### 4.2 构造 TargetCurrent -> CorrectPWM

要求物理样本在有效区间单调。以外部真实电流为 X、实际 PWM 为 Y，对每个目标电流做**反向分段线性插值**：

```text
I0 <= Target <= I1
PWMtarget = PWM0 + (Target-I0)*(PWM1-PWM0)/(I1-I0)
```

规则：
- 禁止外推。
- 零点单独固定为 0 -> 0。
- 非单调、重复电流、不可达目标直接 FAIL。
- 整数计算使用足够宽的中间类型并做边界检查。

### 4.3 顶端覆盖不足

若第一轮最大物理电流仍低于 CalibrationSpan，例如 50W/36V：目标 1400mA、默认 PWM 后外部只测 1342mA，则不能外推声明校准成功。

只允许 calibration-only 的**少量有界端点探测**：
- 用最后两个物理样本估计下一候选 PWM；
- 每次候选受 PWM、I-V、电流、功率、安全状态约束；
- 探测次数严格限制；
- 每个候选必须由外部标准仪器重新测量；
- 无法安全覆盖目标则 FAIL。

这不是 11 点逐点固定步长搜索。

## 5. 采样校准

同一轮物理稳定点直接生成：

```text
OCO raw       -> external actual output current
BL current raw -> external input current
BL power raw   -> external input power
BL voltage raw -> voltage correction/gain
```

例如目标 1400mA，但第一次实际只有 1342mA、未经校正 OCO 显示 1362mA：
- Output BUILD 使用 `PWM -> 1342mA` 作为物理响应样本；
- OCO 使用该 OCO raw -> **1342mA**；
- 绝不能把 OCO raw 强行映射到目标 1400mA。

## 6. STAGE / APPLY / VERIFY / COMMIT

244B 校准数据生成后：

```text
STAGE
  -> APPLY（只临时生效）
  -> 第二轮物理 VERIFY
  -> PASS 后 COMMIT
```

VERIFY 必须重新输出并重新测量，而不是只检查第一轮拟合残差：
- 外部实际输出电流 vs TargetCurrent；
- corrected OCO vs 外部实际输出电流；
- corrected BL Voltage/Current/Power vs 外部标准仪器。

未达到项目容差（量产目标默认 ±1%，具体按测试规范）不得 COMMIT。

## 7. 运行时曲线优先级

```text
brightness + persisted SET_OUTCUR
  -> TargetCurrent = SET_OUTCUR * brightness / 100
  -> 若有效校准曲线覆盖 TargetCurrent：PWL 插值得 CorrectPWM
  -> 否则：严格回退历史 SET/HWMAX 默认公式
```

曲线不外推。修改 SET/HWMAX 后，只要新的 TargetCurrent 仍在曲线覆盖范围即可继续使用；超范围自动回退，不删除曲线。

## 8. 多电压结论

当前 244B 仍是一条一维 `Current -> PWM` 曲线。允许在任意规格节点建立曲线，但不能仅凭算法假设一条曲线跨全部 Vout 都满足 ±1%。

量产验证需要至少选择代表性低/中/高 Vout 做交叉验证。如果“同一目标电流所需 PWM”随 Vout 的差异超过精度预算，则下一协议版本才考虑 Vout 补偿/多曲线/2D LUT；V3 不伪造跨电压精度。

## 9. 六型号共同实现

所有校准公式、BUILD、PWL、APPLY/VERIFY、运行时 fallback 都是通用逻辑。型号差异仅来自 Product Profile：Hardware Max、默认 SET/HWMAX、Rs、额定功率、I-V 表和安全边界；禁止写 50W 特例分支。
