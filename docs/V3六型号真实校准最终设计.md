# V3 六型号真实校准最终设计

> 适用：50W / 75W / 100W / 150W / 200W / 240W 一体化电源。本文是 `fix/v3-real-calibration-20260831` 的 V3 校准唯一实施口径。旧的 50W 专项、36V-only、OCO 11点采样PWL、复杂工艺容差门禁等描述不再作为实现依据。

## 1. 术语唯一含义

- `SET_OUTCUR`：当前设备 Factory 额定输出电流。正常运行时用于 `TargetCurrent = SET_OUTCUR * brightness / 100`。
- `HWMAX_OUTCUR`：当前设备 Factory PWM 满量程电流分母，也是历史未校准调光公式的分母。
- `Hardware Max`：Product Profile 中不可突破的产品硬件能力/安全上界。
- `I-V Limit(Vout)`：Product Profile 在指定输出电压下允许的最大输出电流。
- Product Profile 中的 Default SET / Default HWMAX 只用于默认值、初始化或资料展示，**不得要求当前设备 CAP 值必须等于 Default 值**。
- 校准流程不得修改当前设备 SET/HWMAX。

未校准、无有效曲线、或运行目标超出有效曲线覆盖范围时，默认调光基线保持：

```c
PWM = percent * SET_OUTCUR * PWM_USEFUL_RANGE /
      (HWMAX_OUTCUR * 100U);
```

禁止把任一 I-V 限流值写回或替换 `HWMAX_OUTCUR`。

## 2. 正式校准电压与 CalibrationSpan

上位机默认选择 36V，正式量产校准允许选择：

```text
36 / 40 / 44 / 48 / 52 / 56 V
```

25/29/32V 可以存在于 Product I-V 低压数据中，但不是当前量产正式校准选择。

```text
CalibrationSpan = min(
    current CAP.HWMAX,
    Product I-V Limit(selected Vout),
    Product Hardware Max,
    mandatory safety envelope
)
```

`SET_OUTCUR` 不参与 `CalibrationSpan` 计算。`BEGIN` 由上位机明确传入 `calibrationVoltage01V` 与 `calibrationSpanMa`，固件校验并保存本次会话边界。

## 3. BUILD：先完整采集，不做精度门禁

固定正式点：

```text
Level = 0,20,40,...,200
Percent = 0,10,20,...,100
```

目标轴：

```text
TargetCurrent[i] = CalibrationSpan * Level[i] / 200
```

BUILD 必须绕过已保存校准曲线，使用历史 SET/HWMAX 默认传递产生实际 PWM，测量真实物理对象：

```text
ActualPWM -> ExternalActualIout
```

每点只执行：

```text
SET_POINT
-> 等待固定 Settling Delay
-> 固定采样 N 次
-> MEDIAN
-> 保存该点
```

BUILD 阶段**不得**因为以下内容停止校准：

- 输出误差百分比；
- MCU采样误差百分比；
- Peak-to-Peak 百分比；
- 相对变化率；
- Low/Main/High tolerance；
- 低输出下因仪器分辨率导致的较大百分比波动。

BUILD 可阻断的只有安全和数据可信性问题，例如：Profile/Fingerprint 不匹配、SET/HWMAX关系非法、CalibrationSpan越界、真实 Fault、RAW无效或过期、仪器/MQTT断线、PWM回读不一致、电子负载状态异常等。

## 4. 输出控制校准：11点 inverse PWL

输出控制校准固定为：

```text
11点实际 PWM -> 外部仪器实际 Iout
                ↓
           inverse PWL
                ↓
TargetCurrent -> CorrectPWM
```

外部电子负载/标准仪表的实际输出电流是 Output Fit 的真值。禁止使用 MCU corrected current 作为 Output Fit 真值。

规则：

- 0点固定 `0mA -> PWM 0`；
- 物理 `PWM -> Iout` 必须整体单调；
- inverse PWL 禁止外推；
- 如果100%第一轮实际电流未覆盖 `CalibrationSpan`，只允许 calibration-only 的有界端点探测，直到形成物理覆盖或达到安全 PWM 上限；
- 100%覆盖判断只判断“是否覆盖目标电流”，不使用精度容差判断是否合格。

## 5. 输出电流采样校准：两点 Offset + Gain

OCO 输出电流采样校准固定为两点线性模型：

```text
0%  -> Offset Raw
90% -> Gain Anchor Raw + 外部仪器实际输出电流
```

公式语义：

```text
Current = max(0, Raw - OffsetRaw) * Gain
```

高点固定使用 90%，原因是保持较高信噪比，同时避开100%保护/饱和边缘。

90% Gain 的参考电流必须使用**外部仪器实际测得 Iout**，不是 TargetCurrent。

### 244B兼容说明

V3 payload 长度和版本保持不变。OCO wire 区仍保留 11 个 `Raw -> Current` pair，但这些点必须全部由同一个 `0% Offset + 90% Gain` 直线生成，并与 Output TargetCurrent 轴一致。

因此：

> wire 上是11个共线兼容点；算法上只有两点 Offset+Gain。禁止把它重新解释成11点独立 OCO PWL。

固件 payload validator 必须拒绝不共线的 OCO 11点表。

## 6. BL0942 输入采样

本轮冻结仅改变 OCO 输出电流采样模型。BL0942 当前语义保持：

- BL Voltage：GainQ24；
- BL Current：现有 Raw -> external input current 校准；
- BL Power：现有 Raw -> external input power 校准。

后续若要简化 BL 校准，应另立版本，不得与 OCO 两点方案混为一谈。

## 7. STAGE / APPLY / VERIFY / COMMIT

正确流程：

```text
BUILD 11点
-> FIT
-> STAGE
-> APPLY        # 曲线已写入设备RAM并真正生效
-> QUICK/FULL VERIFY
-> COMMIT Flash
-> READ + CRC + Byte Compare
-> RELEASE
```

`APPLY` 后的 `SET_OUTPUT` 必须使用 staged `TargetCurrent -> CorrectPWM` 曲线，禁止回退默认 SET/HWMAX 公式，否则 VERIFY 验证的不是最终曲线。

VERIFY 必须重新使用仪器测量：

```text
输出控制误差 = ExternalActualIout vs TargetCurrent
采样误差     = MCU Corrected Iout vs ExternalActualIout
```

### VERIFY 的关键原则

非零点精度是**测量结果和质量报告**，不是校准流程的前置或中途门禁。

某个点误差较大时：

```text
记录误差
-> 继续下一个 QUICK/FULL 点
-> 完成整条验证曲线
```

不得因为隐藏的 1%/2%/3%/5% 容差立即 `FAIL -> SAFE OFF`，导致校准曲线还没有完整验证。

COMMIT 的自动硬门禁只包括安全、数据有效性、曲线合法性、物理覆盖、Payload结构、CRC、Flash与READBACK一致性。产品质量是否满足目标精度由最终误差报告/MES质量规则判断，不与校准算法本身混在一起。

## 8. QUICK / FULL 与误差报告

QUICK/FULL 是上位机保留的固定验证模式，点集由软件内部常量决定，操作员不编辑单个百分比，也不编辑各区间容差。

验证完成后必须生成三段报告：

```text
0-30%
30-80%
80-100%
```

每段至少报告：

- 输出控制平均相对误差；
- 输出控制最大相对误差；
- MCU采样平均相对误差；
- MCU采样最大相对误差。

0-30% 额外报告平均/最大绝对 mA 误差；0%不计算相对误差，避免低电流下百分比被仪器分辨率、零漂和噪声放大。

## 9. 上位机可配置项边界

量产页面只保留：

- 预期 Product Profile；
- 校准电压：36/40/44/48/52/56V，默认36V；
- QUICK/FULL；
- DC5200端口、连接、测试回读；
- 电子负载端口、连接、测试回读、INPUT OFF；
- 每点采样次数；
- 输出切换后的 Settling Delay；
- 校准曲线、验证曲线、误差报告。

不再向操作员暴露或要求填写 Tolerance/Fitting/Verification/Session 等复杂工艺表单。

## 10. 运行时

正常业务调光：

```text
brightness + current SET_OUTCUR
-> TargetCurrent = SET_OUTCUR * brightness / 100
-> 有有效且覆盖目标的 committed Output PWL：TargetCurrent -> CorrectPWM
-> 否则回退历史 SET/HWMAX 默认公式
```

校准曲线不外推，且不得改变正常保护、安全仲裁和故障关断。
