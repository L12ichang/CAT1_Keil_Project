## 2. P-CAT1 规划任务

只做审计和计划，不实现业务代码。必须产出：

- 当前 BL0942 23 字节帧字段、校验、换算和并发所有权表；
- ADC/PWM/保护/渐变/MQTT 的调用链和拟修改点；
- 当前 Flash 全地址占用和校准 A/B 槽可行性；
- 现有协议逐字节表、黄金向量和错误码表的建立方法；
- F0–F5 可独立提交的文件级任务包、依赖和测试命令；
- 明确哪些结论仅源码支持、哪些需 Keil/MAP、哪些需实机；
- 复核本任务书，发现不准确处只在规划结果中列出建议，不擅自放宽门槛。

## 3. I-CAT1 实现任务

实现集成者可以使用同模型 `gpt-5.6-luna / max` 子代理处理互不重叠的只读分析、测试夹具或独立模块；重叠核心文件由集成者串行修改。建议任务包：

### WP-F0 协议与测试夹具

- 将现有协议原件转为字段表和黄金二进制向量；
- 编写 encode/decode/CRC 往返测试；
- 先提交文档与测试，不在字段未确认时猜测实现。

### WP-F1 原始快照

- 在 BL0942 唯一读取链发布原始寄存器；
- 分别发布 BL0942 与 ADC/PWM 快照，保留各自 seq/tick/age，再做无撕裂聚合；不得伪造同一采样时刻；
- 增加并发一致性和过期数据测试；
- 不改变 `EleInfo` 的既有语义。

### WP-F2 会话与安全

- 实现 `BEGIN/HEARTBEAT/SET_POINT/RAW/ABORT`；
- 接入现有 MQTT 请求 ID 和 ACK 机制；
- 增加租约、幂等、互斥、保护抢占、复位/掉线安全关断；
- 处理校准中 MCU 复位后 normal soft-start 可能恢复 100% 输出的问题，必须实现并验证 boot-inhibit 或等效硬件联锁契约；
- 重新核实输出过流/过功率检测是否实际启用；未启用时不得把它列为安全保障；
- 与 Factory 写、普通调光和 OTA 明确冲突规则。

### WP-F3 曲线与采样

- 实现 11 点单调校验和分段线性插值；
- 把运行时校正放在正确控制/采样层，保留保护和渐变；
- 对 120mΩ/50mΩ 上下文做强校验；
- 做整数定点溢出、舍入、边界和无效配置测试。

### WP-F4 存储与回读

- 先完成当前分支 Flash/MAP 地址审计；
- 实现暂存、整体验证、非活动槽写入、回读和原子提交；
- 故障注入覆盖擦除后、分片中、payload 后、commit 前等断电点；
- 配置损坏或上下文不匹配时保留并回退旧有效记录。

### WP-F5 集成证据

- 运行主机单元测试、ARM GCC 语法检查和 `git diff --check`；
- 与 `tc` 的黄金 MQTT 报文和模拟器联调；
- 在可用的 Windows/Keil 环境做两个 target 干净构建与 MAP 审计；不可用时明确标记待办；
- 输出 HIL 操作清单，不虚构实机结果。

## 4. R-CAT1 审核任务

I-CAT1 完成并形成中文分阶段提交后，必须创建独立 `gpt-5.6-sol / max` 项目任务，从实现分支审查：

- 协议是否与黄金向量逐字节一致；
- BL0942 是否仍只有一个读取所有者，快照是否可能撕裂/过期；
- 校准是否绕过保护、渐变或正常命令仲裁；
- MCU 复位/看门狗/棕断后是否会由启动路径恢复满功率，boot-inhibit 是否抗掉电损坏和永久锁死；
- 租约、重复包、超时、复位、保护、OTA、并发写是否安全；
- 定点算法的溢出、舍入、单调性和 0/100% 边界；
- Flash 地址、擦写粒度、A/B 提交、CRC 和掉电恢复；
- 测试是否验证真实副作用，是否错误地把 ACK 当成完成；
- Keil/MAP/HIL 证据边界是否被如实陈述；
- 每个 Git 提交是否中文、可审、单一职责且没有无关改动。

审核必须先列发现并按严重级别排序。存在 P0/P1 时退回 I-CAT1 修复并复审；不能只给概括性“通过”。

## 5. Git 纪律

- 每个 WP 至少形成一个可独立审核的中文提交；
- 提交前执行 `git status --short`、精确暂存、相关测试、`git diff --cached --check`；
- 不修改或回退用户已有改动；不提交历史构建产物替代当前证据；
- 当前 `.gitignore` 可能整体忽略 `tests/`、Python 和旧校准工具路径；新增版本化测试必须使用精确 allowlist 并由审核者确认，不能把本地残留测试当成仓库证据；
- 规划任务不直接改实现分支；实现与审核各用独立 Codex 工作树；
- 审核通过后才推送实现任务分支，禁止自动合并主分支。
