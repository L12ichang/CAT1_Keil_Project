# PWM 与计量校准统一实施方案

## 1. 目标与边界

同一份固件适配 50W、60W、75W、100W、150W、200W、240W。固件不保存全部功率段的 profile 表，也不根据可变的额定电流猜测型号；只保存当前设备的工厂硬件参数和当前设备的校准结果。

本方案覆盖：

- PWM 到输出电流的 21 点曲线校准；
- 输入 BL0942 的电压、电流、有功功率、频率、能量校准；
- 输出 ADC 的电压、电流校准，输出功率由校准后的同帧电压和电流计算；
- 正常 MQTT `EleInfo` 上报统一使用校准后的工程量；
- A/B Flash 掉电安全保存、旧版曲线迁移、工站自动化和离线故障注入。

设备未上电时只允许源码、构建、主机测试和 Mock 验证，不执行 J-Link 写入、复位、PWM 输出或电子负载输出。

## 2. 参数语义

| 参数 | 含义 | 是否会导致校准失效 |
|---|---|---|
| `HWMAX_OUTCUR` | 硬件和保护允许的绝对最大电流 | 会 |
| `CAL_MAX_OUTCUR` | 当前 PWM 曲线 100% 点对应的安全校准满量程 | 会；保存在 PWM 校准段 |
| `SET_OUTCUR` | 用户配置的运行额定电流，必须 `<= CAL_MAX_OUTCUR` | 不会 |
| `OUTPUT_CUR_SENSOR` | 当前设备输出采样电阻，单位 mΩ | 会 |
| `CX`、板级/算法版本 | 输入计量拓扑上下文 | 会 |
| 亮度、运行功率限制 | 运行目标 | 不会 |

正常 PWM 映射：

1. `target_ma = brightness_percent * SET_OUTCUR / 100`；
2. 如果启用运行功率限制，再用校准后的输出电压计算电流上限；
3. 将 `target_ma / CAL_MAX_OUTCUR` 映射到 21 点曲线并插值；
4. 所有原有温度、输入电压和过流保护仍在最终输出前生效。

因此同一台设备修改 `SET_OUTCUR` 只改变可用曲线范围，不需要重新校准。`SET_OUTCUR`、亮度和功率限制不得进入校准上下文 CRC。

## 3. 计量模型

每个计量通道使用固定点线性模型：

`engineering = max(0, raw - zero_raw) * gain_q24 / 2^24`

通道为输入电压、输入电流、输入有功功率、输入频率、输出电压、输出电流；能量另保存 CF 计数到 0.01Wh 的 `gain_q24`。所有乘法使用 64 位中间值并做饱和、四舍五入和范围检查。

- 输入 PF 由同一 BL0942 原始帧校准后的 `P/(V*I)` 计算；
- 输出功率由同一输出快照校准后的 `V*I` 计算；
- 输入有功功率仍独立使用 WATT 原码校准；
- 能量只使用校准后的 CF 计数作为累计权威，不再同时维护互相漂移的两套算法；
- 没有有效计量校准段时继续使用旧公式，但状态和校准接口必须明确标记为 fallback，禁止误报“已校准”。

首版只实现统一线性模型。只有跨功率点残差证明单段线性无法达到验收门限时，才升级为分段模型，避免用型号经验补丁掩盖硬件或采样问题。

## 4. Flash 与兼容

继续使用：

- A 槽 `0x08005C00`；
- B 槽 `0x08007400`；
- 每槽保留 `0x100` 字节。

v2 记录固定 240 字节，包含外层序号/状态、独立 PWM 段、独立 Meter 段、记录 CRC 和最后写入的有效标记。两个段分别保存上下文 CRC 和段 CRC；更新一个段时 copy-forward 另一个有效段。

启动同时识别 v1 和 v2。有效 v1 曲线在 RAM 中迁移为：

- PWM 有效；
- `CAL_MAX_OUTCUR =` 迁移时设备的 `SET_OUTCUR`；
- Meter 为空。

启动迁移不写 Flash；第一次提交任一 v2 段时才写到非活动槽。任何 CRC、范围、上下文或撕裂记录异常只使对应段失效，并保留另一个独立有效段。有效标记必须最后写入并读回验证。

## 5. 校准会话

校准会话保持独占和 fail-safe：进入会话即关闭输出并锁住正常调光；超时、通信错误、保护触发、工站异常或 abort 都必须先强制输出为零。

推荐顺序：

1. 读取并核对当前设备硬件参数和上下文 CRC；
2. 输出关闭时采集输出电流/功率零点；
3. 用标准仪表在至少两个有效量程点拟合输入、输出计量系数；
4. 临时应用计量系数，比较高分辨率工程量和最终 MQTT 舍入结果；
5. 以 `CAL_MAX_OUTCUR` 为 100% 目标生成 21 点 PWM 曲线；
6. 临时联合应用 Meter + PWM，在多个亮度与多个 `SET_OUTCUR` 下复测；
7. 明确授权后提交 A/B Flash，读回、重启再验证；
8. 后续修改 `SET_OUTCUR` 不重做校准。

正常 `EleInfo` 不暴露原始 ADC/BL0942 数据。原码、临时系数和写入动作只存在于校准协议中，并受会话、序号、上下文、输出为零和显式 commit 门禁保护。
