# Calibration V3 实现证据与待审核清单

> 当前文件只记录 V3 证据边界，不再保留 V2、旧功率专项参数或旧默认值。

## 已冻结源码语义

1. Output：11点真实物理 `PWM -> External Iout`，上位机 inverse PWL 得到 `TargetCurrent -> CorrectPWM`。
2. OCO：0% Offset + 90% Gain 两点线性校准；244B OCO wire 区仅作11个共线兼容点。
3. BUILD：所选电压 CalibrationSpan -> TargetCurrent/HWMAX 传递，只执行 Settling Delay + 固定采样次数 + MEDIAN；精度百分比和波动百分比不作为收点门禁。
4. APPLY/VERIFY：`SET_OUTPUT` 使用 staged PWL；QUICK/FULL 完整采集并记录误差，不因非零误差提前终止。
5. 正常运行：`TargetCurrent = SET_OUTCUR * brightness / 100`；有有效 committed PWL则使用，否则回退历史 SET/HWMAX 公式。
6. 正式校准电压：36/40/44/48/52/56V，默认36V。
7. CalibrationSpan 使用当前 CAP.HWMAX、所选Vout的I-V Limit、Product Hardware Max和安全上界，SET不参与。
8. 命令职责分离：`SET_POINT`=按所选电压理论电流校准调光，`PROBE_PWM`=100%端点物理探测，`SET_OUTPUT`=校准后曲线验证调光。
9. SET/HWMAX 在任一非 IDLE 校准状态均不可修改；OCO `Raw <= OffsetRaw` 固定钳位为0。

## 已有源码证据

- staged/committed payload 运行时选择已存在；
- OCO wire 两点共线校验已存在；
- Payload CRC、Flash COMMIT、READ generation/length/CRC/byte compare 链路已实现；

- SET_POINT/PROBE_PWM 单次物理写入与 replay 无重复写入测试已存在；

## 发布判定

校准 Runner 能完成写入并不等于产品精度已经满足量产指标。精度由最终验证报告/MES质量规则判断；不得为了“预先保证精度”重新把误差容差、Peak-to-Peak 或 relative rate 加回 BUILD 前置门禁。
