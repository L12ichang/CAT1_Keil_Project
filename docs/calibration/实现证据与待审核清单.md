## 已实现

1. `sys_product_profile.*` 集中管理编译型号、I-V、功率/电流/电压安全边界、Profile 指纹、上下文生成和 SET_OUTCUR 校验。
2. PWM、安全、输出测量校正、校准服务、Flash 和 MQTT 不再直接引用散落的 50W 校准常量。
3. SET_OUTCUR 全入口先验证后提交；目标电流保持 `brightness × SET_OUTCUR`，表反查后的线值按校准时相同的 Profile I100 PWM 标尺输出，避免较低 SET 二次缩放；HWMAX/MID/RS3 受 Profile 保护。
4. 固定校准电压与 SET_OUTCUR 分层；表保存外部仪表顶点导出的 `calibratedMaxCurrentMa`，较低 SET_OUTCUR 使用表内插值且不得超过该上限。
5. 198 字节表保持不变；Flash v3 记录绑定 Profile、固定电压、`configuredRatedCurrentMa`、`calibratedMaxCurrentMa` 和表 CRC，A/B 地址不变。
6. CAL_MQTT_V2 使用数值 fingerprint、嵌套 `profileContext` 和大端 binding CRC；CAPABILITIES 区分首次校准、普通运行和校准会话非零授权。
7. 绑定电压与已加载/活动校准上下文不一致时，启动、会话和 PWM 均失败关闭。
