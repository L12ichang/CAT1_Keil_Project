# 量产校准安全状态门禁（历史 V2 实现快照）

状态：`LEGACY_V2_IMPLEMENTATION_SNAPSHOT / HIL_PENDING`。本文记录历史 V2 源码门禁与未完成 HIL，不再冻结目标 wire contract。目标 V3、默认 SET_OUTCUR=893mA、默认 HWMAX=1400mA 以及 Calibration 不绑定普通运行授权的口径，以 `done/cat1-product-profile-cal-context-20260817` 上的两份 CAT1 50W 权威文档为准；参见 `docs/CAT1_50W文档口径说明.md`。

## 不能当作安全证据的值

- PWM 计数 `1000` 只是当前软件计数范围；
- `HWMAX_OUTCUR` 是当前编译 Profile 的受保护换算/硬件能力字段，不能单独当作经 HIL 证明的安全上限；
- `FACTORY_OUTCUR_MAX_MA=10000` 只是字段校验上限；
- 当前输出过流、过功率主动关断路径未证明生效。

以上任何值都不是经 50W 硬件验证的安全上限。

## 必须满足的状态契约

1. 历史实现的校准会话使用隔离命名空间 `SV=cal`，wire 字段按 CAL_MQTT_V2 和共享黄金夹具验证；该条只记录旧实现，不再声明最终协议冻结；
2. `BEGIN` 前必须完成能力查询、设备/型号校验和安全前置检查；
3. 产生非零 `SET_POINT` 前，必须持久化 boot-inhibit 并独立回读成功，或由工站硬件电源使能/急停联锁提供等效证明；
4. MCU 复位、看门狗、棕断、MQTT 掉线、租约超时、保护触发和 OTA 开始均必须先保持 PWM/OCO 关闭；
5. `ABORT`、租约失效和故障路径优先于普通调光、计划、Factory reload 与 OTA；
6. 写动作使用幂等序列；动作已执行但发布 ACK 忙时，必须由结果缓存和匹配 `ID/session/op/seq` 回读闭合；
7. 最终成功只能由“业务 ACK + 匹配回读 + 独立仪器验证 + 掉电重启复测”共同判定。

历史 V2 实现在 `BEGIN` 成功 ACK 前先 A/B 持久化 active boot-inhibit；非零点仅在当前编译 Profile 与 MID/RS3/HWMAX 匹配、上下文绑定电压一致、无故障标志、ADC 快照不超过 500ms 且电压/电流/功率限幅通过时输出。普通调光还要求 SET_OUTCUR 不超过表内 `calibratedMaxCurrentMa`。这些是待迁移的旧实现事实，不得被解释为目标 V3 仍要求运行电压或 `calibratedMaxCurrentMa` 授权。

以上只是源码门禁，不等于 50W 实机安全上限已验证。未完成限流电源、电子负载、急停、复位/掉电和保护触发 HIL 前，不得作为量产固件烧录。
