# Calibration V3 安全状态门禁

> 本文件只定义安全/数据可信性门禁，不定义精度容差。算法与流程以 `../V3六型号真实校准最终设计.md` 为准。

## 1. 安全门禁原则

校准允许继续的前提是“可以安全测、数据可信、协议状态合法”，不是“未校准设备已经足够准确”。

必须失败关闭的情况：

- Product Profile / Fingerprint 不匹配；
- `SET_OUTCUR <= 0`、`HWMAX <= 0`、`SET_OUTCUR > HWMAX`、`HWMAX > Product Hardware Max`；
- 所选校准电压或 CalibrationSpan 超出 Product I-V / 安全边界；
- MQTT session、sid、seq、lease 状态非法；
- 真实过温、过压、欠压、过流/过载等硬件 Fault；
- RAW stale/invalid 或所需 valid flags 缺失；
- PWM echo 与本次命令不一致；
- DC5200 / 电子负载掉线或返回非法值；
- 电子负载 INPUT 状态与阶段要求不一致；
- Output 物理曲线严重非单调或目标没有安全覆盖；
- OCO 两点模型或 wire 共线约束非法；
- Payload/CRC/Flash/READBACK 错误。

任何失败路径都必须优先 SAFE OFF，并保持正常保护优先级高于校准业务。

## 2. 不属于安全门禁的内容

以下数据不得阻止 BUILD 收点或使非零 VERIFY 点提前失败：

- Output相对误差%；
- MCU采样相对误差%；
- Peak-to-Peak%；
- relative rate%；
- Low/Main/High tolerance；
- 低输出时由仪器分辨率和零漂放大的百分比波动。

这些属于校准后质量结果，统一进入验证曲线和三段误差报告。

## 3. BUILD

```text
SET_POINT
-> Settling Delay
-> 固定采样N次
-> 校验每个样本安全/有效
-> MEDIAN
-> 保存
```

普通 `SET_POINT` 每次只允许一次 TargetCurrent/HWMAX 校准调光写入。只有100%点未形成物理覆盖时，
上位机才可发送独立 `PROBE_PWM`；固件要求 ACTIVE 会话、有效 lease/seq、100%当前点、
无 Fault 且反馈新鲜。探测写入失败必须 SAFE OFF，且不得留下成功PWM状态。

采样次数达到设定值且数据有效即可结束该点，不再动态等待“百分比稳定”。

## 4. APPLY / VERIFY

APPLY 后 staged Output PWL 必须真实生效。QUICK/FULL 每个点都尽量完整采集：

```text
Output Error   = External Actual Iout vs TargetCurrent
Sampling Error = MCU Corrected Iout vs External Actual Iout
```

非零误差较大时只记录，不触发自动精度失败。只有出现本文件第1节的安全/数据可信性问题才停止。

## 5. 复位与持久化

校准会话期间 MCU 复位、看门狗、掉线、租约超时或异常退出时，不允许自动恢复非零校准输出。Flash COMMIT 成功必须由 generation、length、CRC 与完整 READBACK 共同确认；实机掉电测试仍是量产放行证据，不得由源码测试替代。
