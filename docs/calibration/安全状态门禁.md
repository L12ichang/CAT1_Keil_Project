# 历史实现快照：旧校准安全门禁

> **状态：LEGACY / DEPRECATED / 不得作为新校准安全规范**

本文件原来描述的是 CAL_MQTT_V2 阶段的安全门禁。其中部分“校准安全”规则把 Calibration 当成普通运行授权条件，已经不符合当前设计。

## 1. 仍然有效的安全原则

以下原则继续有效：

- MCU 保留过流、过温、短路等硬件最后保护；
- 校准会话异常、MQTT租约失效、保护触发时必须安全退出校准输出；
- 写动作必须考虑重复包与副作用幂等；
- 上位机必须确认电子负载安全关闭；
- 实机 HIL 不能被主机测试代替。

## 2. 已废弃的旧规则

以下旧逻辑不得继续作为目标实现：

- `CAL_MQTT_V2` 作为最终 Wire Contract；
- Calibration Context 绑定运行输出电压；
- 普通调光必须匹配校准电压；
- 普通 SET_OUTCUR 必须不超过 `calibratedMaxCurrentMa` 才允许输出；
- 缺少 Calibration 时普通非零输出失败关闭；
- HWMAX 与硬件 Hardware Max 合并为同一值；
- 用旧 boot-inhibit 机制把“未校准”设备永久视为不安全设备。

## 3. 当前安全职责

当前目标是：

```text
上位机：决定如何安全地执行校准工艺
固件：执行校准 + 保存/应用Correction + 保留硬件最后保护
```

Calibration 是 Correction，不是普通运行 Permission。

因此：

```text
没有Calibration
→ 使用默认PWM链 + OP_PWM_OFFSET
→ 正常运行
```

只有真实硬件故障、当前活动校准事务的异常控制等原因才可以强制关断。

## 4. 当前电流边界

50W：

```text
Hardware Max = 1680mA
Default HWMAX = 1400mA
Default SET_OUTCUR = 893mA
```

关系：

```text
SET_OUTCUR <= HWMAX <= Hardware Max
```

Hardware Max 是硬件固定绝对边界；HWMAX 是工厂允许的用户配置范围；SET_OUTCUR 是当前用户运行目标。
