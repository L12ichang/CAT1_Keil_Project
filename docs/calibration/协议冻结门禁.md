# Calibration V3 协议冻结门禁

> 当前文件不再保留 V2/旧功率专项参数。V3 算法、上下位机边界和量产流程以 `../V3六型号真实校准最终设计.md` 为唯一设计依据。

## 当前协议语义

- Product Profile / Fingerprint 必须与 CAP 匹配；
- 当前设备 `SET_OUTCUR`、`HWMAX` 来自 CAP/Factory；Product Default 只做参考；
- `CalibrationSpan = min(CAP.HWMAX, Product I-V Limit(selected Vout), Product Hardware Max, safety envelope)`；
- 正式校准电压为 36/40/44/48/52/56V，默认36V；
- BUILD 固定 11点：0/10/.../100%；
- Output 校准为 11点 inverse PWL；
- OCO 校准为 0% Offset + 90% Gain 两点线性；
- 244B OCO wire 11个pair必须共线并与 Output TargetCurrent 轴一致；
- APPLY 后 `SET_OUTPUT` 必须走 staged Output PWL；
- QUICK/FULL 误差是报告数据，不是非零点协议失败条件。

## 硬门禁

协议层只因以下情况拒绝或停止：

- session/sid/seq/state非法；
- Profile/Fingerprint错误；
- SET/HWMAX/Hardware Max关系非法；
- CalibrationSpan或电压超范围；
- RAW stale/invalid；
- 真实硬件Fault；
- Output曲线非单调/覆盖不足；
- OCO两点共线约束失败；
- Payload结构/CRC错误；
- Flash commit失败；
- READBACK generation/length/CRC/bytes不一致。

旧 V2 wire、旧表结构和旧功率专项数值只能从 Git 历史追溯，不得重新作为 V3 实施条件。
