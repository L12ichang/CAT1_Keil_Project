## 2. 本文件描述的旧实现

当前目标分支仍存在旧实现材料，包括：

- `CAL_MQTT_V2`；
- 11点×18B=198B旧表；
- `profileContext`；
- `calibrationVoltage01V`；
- `configuredRatedCurrentMa`；
- `calibratedMaxCurrentMa`；
- `profileBindingCrc32`；
- `profilesCsv`；
- 50W旧默认 `SET_OUTCUR=890mA`；
- 旧逻辑把 HWMAX 与 Product Profile 最大电流混在一起；
- 旧逻辑要求运行电压/SET_OUTCUR/校准上限与 Calibration Context 匹配。

这些内容只说明“当前代码需要被修改的起点”，不代表目标设计。

## 3. 已明确废弃的旧口径

以下旧规则不得继续实现或复制到新协议：

- `CAL_MQTT_V2` 作为最终协议；
- `SET_OUTCUR=890mA` 作为50W新默认值；
- `HWMAX=1680mA` 与 Hardware Max 合并；
- 固定校准电压绑定 Calibration 有效性；
- 当前 SET_OUTCUR 绑定 Calibration 有效性；
- `calibratedMaxCurrentMa` 作为普通运行输出授权上限；
- 无 Calibration 时禁止普通非零输出；
- 设备 CAPABILITIES 返回多功率 `profilesCsv`；
- 每个 ACK 重复返回完整 Profile Context/状态大对象。

## 4. 当前新目标

50W 当前目标参数：

```text
Hardware Max       = 1680mA
Default HWMAX      = 1400mA
Default SET_OUTCUR = 893mA
RS3                = 120mΩ
```

关系：

```text
SET_OUTCUR <= HWMAX <= Hardware Max
```

目标校准 MQTT 统一称为：

```text
Calibration MQTT Protocol V3
```

新 Calibration Flash 数据结构在逐 Byte 结构最终冻结前统一称为：

```text
Target Calibration Record
```

**不得再把新目标称为“Calibration Record V2”。** 当前源码中的 Storage Format 3 只是 Legacy 实现版本，和目标 MQTT Protocol V3 不是同一个版本空间。

## 5. 旧夹具与测试

`protocol/fixtures/CAL_MQTT_V2/` 和 `tools/calibration/test_cal_mqtt_v2.c` 可以保留，用于证明旧协议行为和迁移边界，但不得作为 Protocol V3 的 Golden Vector。

Protocol V3 必须建立独立的字段表、Golden Vector 和跨端测试。
