# 量产校准协议冻结门禁

状态：`FROZEN_BASE_PAYLOAD`（正式 11 点基础 payload 已冻结，额外运行时系数格式未冻结）。

## 已确认的产品边界

- 首期只启用 50W：`MID=1`、额定恒流 `890mA`、输出范围 `36–56V`、`RS3=120mΩ`。
- 校准等级固定为 `0/20/40/.../200`，对应 `0%/10%/.../100%`，共 11 点。
- `<=30%` 的控制与采样误差门槛为 `2%`，`>30%` 为 `1%`；0% 必须使用单独的绝对残余值和关断时间门槛。
- 100W 只记录 `RS3=50mΩ`，MID、额定电流、输出范围和安全上限未确认，禁止启用量产配置。

## 已冻结的基础协议

- 帧：`3A CMD OFFSET LEN DATA SUM 0D 0A`，校验为 `CMD+OFFSET+LEN+DATA` 低 8 位。
- 命令：`24/25/26/27`；偏移：`03/04/05/07/08`。
- 校准表为 11 点 × 18 字节 = 198 字节，等级固定 `0/20/.../200`，多字节字段大端。
- `tools/calibration/test_protocol_gates.c` 使用正式文档黄金 205 字节整帧做字节级 encode/decode 与变异拒绝。
- MQTT 使用 `SV=cal`；变更操作只接受 `CT=W`，`CAPABILITIES/RAW/CONFIG` 只接受 `CT=R`。

## 仍未冻结的扩展

198 字节表没有显式 PWM 计数，也没有 BL0942 输入电压/功率原码和输出电压 ADC 原码。本分支只用表中“仪器输出电流/设备输出电流”生成输出控制反向校正和输出电流采样校正。输入 U/I/P、输出 U 的 `gain+offset` 以及显式 PWM LUT 必须先冻结与 198 字节分离的版本化格式，不得冒充成正式 payload 字段。
